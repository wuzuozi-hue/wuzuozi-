## 运行方式

每个C++文件含独立main，分别编译。例如已安装GCC的终端：

```sh
g++ -std=c++17 -Wall -Wextra -pedantic 06_合并两个有序链表.cpp -o merge_lists
```

再运行生成的程序。PowerShell脚本只适用于原工作区的work/devdocqa-build依赖布局，克隆本归档不会附带工具链。
SQL整份在同一PostgreSQL连接中执行，只使用临时表，观察COMMIT后仍保留的临时数据以及ROLLBACK结果。
Python演示需要psycopg 3及可用PostgreSQL；可用PRACTICE_PG_DSN设置本地练习连接，程序不会输出连接凭据，临时表在连接关闭后清理。它不会自动启动数据库。
