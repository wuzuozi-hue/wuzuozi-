# 学习地图：为 C++ 后端／AI 工程实习服务

用户主语言为 C++，正在开发文档问答后端 DevDocQA。课程的价值在于把“能解释”变成“能独立写、运行、调试、复盘”。不要按 PDF 编号机械从头刷到尾；围绕当前项目和招聘要求取知识点，同时保留基础到进阶的依赖顺序。

## 建议的教学卡片

每次只处理一个紧密知识簇：

1. **概念与反例**：一句话定义；指出最容易混淆的边界，例如 `vector::size` 与 `capacity`、进程与线程、TCP 字节流与消息边界。
2. **最小可运行代码**：给编译/运行命令、预期输出；标明适用环境与可能变化的输出。
3. **看图解释路径**：选一张能回答当前问题的 [配图](figures.md)，讲清图上每个箭头的含义；不用为凑图而贴图。
4. **项目关联**：指出 DevDocQA 哪条请求路径或故障可验证该知识点；MySQL 内容使用独立练习库，和项目里的 PostgreSQL 只比较通用设计概念，SQL 方言、索引与隔离细节要分别验证。没有实际实现过的功能只作为下一步练习，不写成项目成果。
5. **面试口述与小改动**：能在 1 分钟内解释，并独立改变一个参数/输入，预测再验证结果。卡住时记录具体错因，不以背术语代替动手。

## 先后顺序

- 当前阶段先巩固 C++ 的对象生命周期、STL 和双循环/哈希算法；与项目一起学习 Linux 命令、TCP/HTTP、SQL 查询。
- 能独立修改和调试 API 后，再深入异步 I/O、条件变量、索引与事务；MySQL 在独立环境练习，DevDocQA 的数据库操作仍以 PostgreSQL 实际实现为准。
- 红黑树完整插删、内核源码布局、MySQL 引擎内部实现可作为进阶追问；先会解释性质、用途和复杂度，避免把时间全部花在复杂源码复现上。
