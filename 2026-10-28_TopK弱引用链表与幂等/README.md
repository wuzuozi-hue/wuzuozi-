## 在其他环境运行

四份C++练习都是独立程序，每次单独编译。例如在已安装Clang的终端：

```sh
clang++ -std=c++17 -Wall -Wextra -pedantic 01_TopK独立复测.cpp -o topk
```

再运行生成的程序。目录中的PowerShell脚本依赖原本工作区的work/devdocqa-build工具链，单独克隆本仓库不会自带该工具链。
SQL需要PostgreSQL连接，整份文件在同一个连接中执行；仅操作临时表，末尾ROLLBACK。
补丁针对原DevDocQA工程的backend/src/server.cpp，应用前应核对上下文；本仓库不包含完整服务。
