## 算法编译

在本日期目录中，使用支持 C++17 的编译器，例如：

~~~bash
clang++ -std=c++17 -Wall -Wextra -pedantic 01_TopK独立复测.cpp -o topk
./topk
~~~

Windows 的可执行文件通常为 topk.exe；按实际终端运行。
本机验证使用项目已准备的 Clang；工具链不随归档上传。

## 最重要的三处修正

1. reserve 扩容量，不增加 size；shared_ptr 的拥有者数量不等于所管理的值。
2. POST 提交，后台写终态，GET 只读；客户端不查询也不会阻止后台完成。
3. release 归还名额，不删除任务；终态保存成功后再释放，重复释放会漏算容量。
