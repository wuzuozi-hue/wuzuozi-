# 开始前诊断：先做题，后看答案

用途：选择学习起点，不是求职测评。建议 4 小时：编码与作答 150 分钟，运行检查 45 分钟，评分复盘 45 分钟。不使用 AI 或搜索给出答案；允许查编译器报错与自己已有笔记，必须记录用过哪些帮助。

在个人笔记中保存尝试、用时、失败用例和把握程度。总分 100 分，无实际完成就不评分。参考答案单独放在 `baseline-answers.md`。

## A. C++，30 分

**A1，12 分。** 写一个 C++17 `Buffer`：构造时申请 N 个 `int`，析构时释放；禁止复制，支持移动构造与移动赋值。给出 0 大小、移动后对象析构、自移动赋值、作用域结束的测试。可以用标准库管理资源，但说明你采用的所有权策略。评分：生命周期与无泄漏 4，禁止复制 2，移动正确 3，边界测试 3。

**A2，8 分。** 解释并修正下面两个独立片段的问题：

```cpp
const std::string& name() { std::string s = "demo"; return s; }
std::vector<int> v{1, 2};
auto it = v.begin();
v.push_back(3);
std::cout << *it;
```

评分：识别悬空引用 2、修复 2、说明扩容可能导致迭代器失效 2、正确修改容器操作顺序或重新取得迭代器 2。

**A3，10 分。** 实现两个线程各执行 10,000 次加一，最终值必须为 20,000。解释直接 `++counter` 的风险、你采用的同步方法及 `join()` 的作用。评分：无数据竞争 4，等待线程结束 2，解释正确 2，重复执行验证 2。

## B. 算法，30 分

**B1，10 分。** 给定整数数组和目标值，返回两个不同下标使其和为目标值；没有答案返回空。用哈希表完成，处理重复值，解释平均时间/空间复杂度。测试 `[3,3],6`、空数组、负数、无解。评分：正确性 5，边界 3，复杂度 2。

**B2，10 分。** 在非降序数组中找第一个大于等于目标值的位置；不存在返回数组长度。独立写二分，说明区间不变量。测试空数组、重复值、目标小于所有数、目标大于所有数。评分：正确性 5，边界 3，区间解释 2。

**B3，10 分。** 给定有向图邻接表和起点，用 BFS 返回最少边数距离；不可达为 -1。含环时不能无限循环。测试单点、自环、重复边、不可达点。评分：队列与遍历 4，首次访问与距离 3，测试及 O(V+E) 解释 3。

## C. 系统与网络，20 分

**C1，8 分。** 分别解释进程、线程、虚拟内存；写出一个需要锁的共享状态和一个不必共享的局部状态。评分：进程地址空间 2，线程共享及独立状态 2，虚拟地址映射 2，具体例子 2。

**C2，6 分。** 从客户端发送 HTTP 请求到服务端返回，说明 TCP 连接、HTTP 消息及状态码的关系。解释为什么一次 `send` 不对应接收方的一次 `recv`，以及为何需要消息边界。评分：分层 2，字节流 2，边界 2。

**C3，6 分。** 一个 AI 调用需要 20 秒。同步阻塞事件循环有什么影响？画出提交任务返回 ID、后台执行、轮询结果的流程，指出至少两处失败。评分：阻塞影响 2，任务流程 2，失败及状态 2。

## D. SQL 与数据一致性，20 分

给定 `documents(id, name, status, created_at)` 和 `jobs(id, document_id, status, created_at)`。

**D1，8 分。** 写 SQL：查询最新 10 个就绪文档；查询每个文档失败任务数量（没有失败任务也显示 0）。评分：过滤/排序/限制 3，LEFT JOIN 与条件位置 3，计数正确 2。

**D2，6 分。** 插入文档和其入库任务时为何应在同一事务内？任务插入失败如何处理？为什么不能在数据库事务里等待模型 120 秒？评分：原子性 2，回滚 2，长事务资源与锁 2。

**D3，6 分。** 对 D1 的最新文档查询提出一个候选索引，说明如何验证实际收益；说明索引的一项写入代价。评分：与过滤排序对应 2，查询计划及测量 2，代价 2。

## 评分后的行动

| 分数/现象 | 行动 |
|---|---|
| 80—100 且能独立解释 | 按路线推进，增加故障定位和设计追问 |
| 60—79 | 每周基础时间先补扣分最多的两项 |
| 低于 60 | 前两周收缩扩展功能；先完成 C++ 所有权、基本算法和 SQL |
| 编码能运行但口述不清 | 不算通过；重新解释数据流并独立做变体 |

记录格式：`日期 / 题号 / 用时 / 得分 / 独立或借助提示 / 失败原因 / 复习日期`。评分只用于调整学习，不能直接写成面试能力认证。
